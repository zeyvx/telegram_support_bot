# Telegram Support Bot

Telegram-бот службы поддержки на Python с использованием aiogram 3 и SQLite.

Бот предназначен для организации поддержки пользователей: пользователь создаёт заявку, администратор берёт её в работу, отвечает и завершает обработку. После ответа пользователь может оценить качество помощи.

## Возможности

### Пользователь

- выбор языка: русский или узбекский;
- отправка заявки в службу поддержки;
- выбор категории проблемы;
- добавление текста к заявке;
- прикрепление файла или фотографии;
- просмотр своих заявок;
- отмена новой заявки;
- получение ответа администратора;
- оценка помощи от 1 до 5;
- возможность сообщить, что ответ не помог, и продолжить работу с заявкой.

### Администратор

- просмотр новых заявок;
- просмотр всех заявок с пагинацией;
- просмотр отклонённых заявок;
- просмотр подробной информации о заявке;
- взятие заявки в работу;
- ограничение до 3 одновременно взятых заявок на одного администратора;
- отправка ответа пользователю;
- повторный ответ по заявке;
- завершение заявки;
- возврат заявки в очередь;
- отклонение заявки с указанием причины;
- возврат отклонённой заявки в очередь;
- просмотр собственной статистики;
- просмотр рейтинга администраторов;
- управление администраторами и их ролями.

## Жизненный цикл заявки

Заявка проходит через несколько состояний:

- `Новая` — заявка создана и ожидает администратора;
- `В работе` — заявка взята администратором;
- `Завершена` — обработка завершена;
- `Отклонено` — заявка отклонена администратором с причиной;
- `Отменена` — заявка отменена пользователем.

Если пользователь считает ответ недостаточным, он может сообщить об этом, после чего работа с заявкой может быть продолжена.

## Рейтинг

После завершения обработки пользователь может поставить оценку от 1 до 5.

На основе оценок бот хранит данные о работе администраторов и формирует рейтинг. Также для администраторов доступна статистика по обработанным заявкам.

## Роли администраторов

В проекте предусмотрена система приоритетов администраторов:

- `admin`;
- `senior admin`;
- `moderator`;
- `super admin`.

Права и доступные действия зависят от роли и приоритета администратора.

## База данных

Бот использует SQLite и автоматически создаёт необходимые таблицы при запуске.

Основные таблицы:

- `users` — пользователи и выбранный язык;
- `requests` — заявки, их категории, статусы, администраторы и причины отклонения;
- `admins` — администраторы, роли и приоритеты;
- `ratings` — оценки пользователей и рейтинг администраторов.

Для часто используемых запросов создаются необходимые индексы.

## Настройка

Создайте файл `.env` в корне проекта. Можно использовать `.env.example` как шаблон:

```env
BOT_TOKEN=токен_бота
OPERATOR_PHONE=номер_оператора
SUPER_ADMIN_ID=123456789
```

`SUPER_ADMIN_ID` — Telegram ID главного администратора. Значение должно быть числом.

Не добавляйте настоящий `.env` в Git. Файл `.env` должен оставаться локальным.

## Установка

Клонируйте репозиторий и перейдите в папку проекта:

```bash
git clone https://github.com/zeyvx/telegram_support_bot.git
cd telegram_support_bot
```

Создайте виртуальное окружение:

```bash
python -m venv .venv
```

Windows:

```bash
.venv\Scripts\activate
```

Linux/macOS:

```bash
source .venv/bin/activate
```

Установите зависимости:

```bash
pip install -r requirements.txt
```

Создайте `.env`, заполните необходимые значения и запустите бота:

```bash
python main.py
```

SQLite-база данных и её структура создаются автоматически при первом запуске.
